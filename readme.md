  Pilares de la POO
¿Cuáles son los 4 pilares de la programación orientada a objetos y qué aporta cada uno?
Los pilares del poo son Abstracción, Encapsulación, Herencia y Polimorfismo
¿Cuál es la diferencia entre encapsulamiento y abstracción?
La diferencia es que la abstraccion se enfonca en ocultar detalles inecesarios mientras que el encapsulamiento se refiere a protejer datos y codigo dentro de una unidad y controlar el accesos a estos
¿Qué pilar permite a las subclases sobrescribir métodos?
El pilar que permite sobreescribir metodos es el polimorfismo ya que este permite a las subclases implementar metodos con el mismo nombre pero con diferente funcionalidad.


    Decorador
¿Qué es un decorador en Python y para qué se utiliza comúnmente?
Un decorador en Python es una función que se aplica a otra función para modificar su comportamiento sin alterar su código original. Se usa comúnmente para tareas como validaciones, registro de llamadas, medición de tiempo de ejecución y control de acceso.
 
 ¿Como se aplica a una función? 
 Un decorador se aplica a una función colocando la sintaxis @nombre_del_decorador justo antes de la definición de la función.
 
  ¿Qué función interna suele tener un decorador? 
  Un decorador suele tener una función interna llamada wrapper (o similar), que actúa como envoltura para modificar o extender el comportamiento de la función original.
